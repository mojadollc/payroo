# Firebase Deployment Troubleshooting Guide\n\n## Common Issues & Solutions\n\n---\n\n## 1. Firebase CLI Issues\n\n### Issue: \"firebase: command not found\"\n\n**Cause**: Firebase CLI not installed globally\n\n**Solution**:\n```bash\nnpm install -g firebase-tools\n```\n\nVerify:\n```bash\nfirebase --version\n```\n\n---\n\n### Issue: \"You do not have permission to view this project\"\n\n**Cause**: Not logged in or wrong Google account\n\n**Solution**:\n```bash\n# Logout\nfirebase logout\n\n# Login with correct account\nfirebase login\n\n# Verify project\nfirebase projects:list\n```\n\nShould show: `sari-pos-88979`\n\n---\n\n### Issue: \"Cannot find module 'firebase-tools'\"\n\n**Cause**: Firebase CLI installed locally instead of globally\n\n**Solution**:\n```bash\n# Install globally\nnpm install -g firebase-tools\n\n# Or use npx (no installation needed)\nnpx firebase deploy --only hosting\n```\n\n---\n\n## 2. Build Issues\n\n### Issue: \"npm run build\" fails\n\n**Cause**: Missing dependencies or TypeScript errors\n\n**Solution**:\n```bash\n# Clean install\nrm -rf node_modules package-lock.json\nnpm install\n\n# Try building again\nnpm run build\n```\n\n---\n\n### Issue: \"Cannot find module '@/components/...'\"\n\n**Cause**: Path alias not configured or file doesn't exist\n\n**Solution**:\n1. Check file exists at the path\n2. Verify `tsconfig.json` has correct paths\n3. Restart IDE\n4. Run `npm run build` again\n\n---\n\n### Issue: \"TypeScript error: Property 'X' does not exist\"\n\n**Cause**: Type mismatch or missing type definition\n\n**Solution**:\n```bash\n# Check for errors\nnpm run lint\n\n# Fix TypeScript errors in the file\n# Then rebuild\nnpm run build\n```\n\n---\n\n### Issue: Build takes too long (>5 minutes)\n\n**Cause**: Large dependencies or slow machine\n\n**Solution**:\n```bash\n# Use faster package manager\npnpm install\npnpm run build\n\n# Or use yarn\nyarn install\nyarn build\n```\n\n---\n\n## 3. Deployment Issues\n\n### Issue: \"firebase deploy\" fails with \"Permission denied\"\n\n**Cause**: Not authenticated or wrong project\n\n**Solution**:\n```bash\n# Re-authenticate\nfirebase logout\nfirebase login\n\n# Verify correct project\nfirebase projects:list\n\n# Check .firebaserc\ncat .firebaserc\n\n# Should show: \"default\": \"sari-pos-88979\"\n```\n\n---\n\n### Issue: \"Deployment failed: 403 Forbidden\"\n\n**Cause**: Firebase project permissions issue\n\n**Solution**:\n1. Go to [Firebase Console](https://console.firebase.google.com)\n2. Select project `sari-pos-88979`\n3. Go to Project Settings → Users and permissions\n4. Verify your account has \"Editor\" role\n5. Try deployment again\n\n---\n\n### Issue: \"Deployment failed: 500 Internal Server Error\"\n\n**Cause**: Firebase service issue (temporary)\n\n**Solution**:\n```bash\n# Wait a few minutes\n# Then try again\nfirebase deploy --only hosting\n```\n\nIf persists:\n```bash\n# Try with verbose output\nfirebase deploy --only hosting --debug\n```\n\n---\n\n### Issue: \"Deployment failed: ENOENT: no such file or directory\"\n\n**Cause**: Build folder missing or corrupted\n\n**Solution**:\n```bash\n# Rebuild\nrm -rf .next\nnpm run build\n\n# Deploy\nfirebase deploy --only hosting\n```\n\n---\n\n### Issue: Deployment hangs or times out\n\n**Cause**: Large build or slow connection\n\n**Solution**:\n```bash\n# Cancel (Ctrl+C)\n# Wait a minute\n# Try again\nfirebase deploy --only hosting\n\n# Or with timeout\nfirebase deploy --only hosting --timeout 600\n```\n\n---\n\n## 4. Post-Deployment Issues\n\n### Issue: App shows old version after deployment\n\n**Cause**: Browser cache or service worker cache\n\n**Solution**:\n\n**Option 1: Hard Refresh**\n```\nWindows/Linux: Ctrl+Shift+R\nMac: Cmd+Shift+R\n```\n\n**Option 2: Clear Service Worker**\n```\n1. Open DevTools (F12)\n2. Go to Application → Service Workers\n3. Click \"Unregister\"\n4. Refresh page\n```\n\n**Option 3: Clear All Cache**\n```\n1. Open DevTools (F12)\n2. Go to Application → Storage\n3. Click \"Clear site data\"\n4. Refresh page\n```\n\n---\n\n### Issue: PWA install prompt not showing\n\n**Cause**: Multiple possible reasons\n\n**Solution - Check 1: Verify HTTPS**\n```\n✅ Firebase Hosting uses HTTPS by default\nNo action needed\n```\n\n**Solution - Check 2: Verify Manifest**\n```\n1. Open DevTools (F12)\n2. Go to Application → Manifest\n3. Should load without errors\n4. Check all fields are present\n```\n\n**Solution - Check 3: Verify Service Worker**\n```\n1. Open DevTools → Application\n2. Go to Service Workers\n3. Should show \"activated and running\"\n4. Scope should be \"/\"\n```\n\n**Solution - Check 4: Check Browser Support**\n```\n✅ Chrome 90+\n✅ Edge 90+\n✅ Firefox 92+\n✅ Safari 16.4+\n\nIf using older browser, upgrade\n```\n\n**Solution - Check 5: Clear Cache**\n```\n1. DevTools → Application → Storage\n2. Click \"Clear site data\"\n3. Refresh page\n4. Prompt should appear\n```\n\n---\n\n### Issue: Service worker not updating\n\n**Cause**: Old service worker still active\n\n**Solution**:\n```bash\n# Option 1: Unregister service worker\n# DevTools → Application → Service Workers → Unregister\n\n# Option 2: Force update\nfirebase hosting:disable\nfirebase deploy --only hosting\nfirebase hosting:enable\n\n# Option 3: Hard refresh\nCtrl+Shift+R (Windows/Linux)\nCmd+Shift+R (Mac)\n```\n\n---\n\n### Issue: Offline functionality not working\n\n**Cause**: Service worker not caching assets\n\n**Solution**:\n```\n1. Open DevTools → Application\n2. Go to Cache Storage\n3. Should see \"88seven-v1\" cache\n4. If empty, visit pages to populate cache\n5. Then test offline\n```\n\n---\n\n### Issue: App crashes or shows blank page\n\n**Cause**: JavaScript error or missing asset\n\n**Solution**:\n```\n1. Open DevTools (F12)\n2. Go to Console tab\n3. Look for red error messages\n4. Note the error\n5. Fix in code\n6. Rebuild and redeploy\n```\n\n---\n\n## 5. Performance Issues\n\n### Issue: App loads slowly\n\n**Cause**: Large bundle or unoptimized assets\n\n**Solution**:\n```bash\n# Check bundle size\nnpm run build\n\n# Look for large files in .next/static\n# Consider code splitting or lazy loading\n```\n\n---\n\n### Issue: High bandwidth usage\n\n**Cause**: Assets not cached or compressed\n\n**Solution**:\n\nAdd to `firebase.json`:\n```json\n{\n  \"hosting\": {\n    \"headers\": [\n      {\n        \"source\": \"**/*.@(js|css|png|jpg|jpeg|gif|svg)\",\n        \"headers\": [\n          {\n            \"key\": \"Cache-Control\",\n            \"value\": \"public, max-age=31536000, immutable\"\n          }\n        ]\n      }\n    ]\n  }\n}\n```\n\nThen redeploy:\n```bash\nfirebase deploy --only hosting\n```\n\n---\n\n## 6. Rollback Issues\n\n### Issue: Need to revert to previous version\n\n**Solution - Option 1: Quick Rollback**\n```bash\nfirebase hosting:releases:rollback\n```\n\n**Solution - Option 2: Rollback to Specific Version**\n```bash\n# List all versions\nfirebase hosting:releases:list\n\n# Rollback to specific version\nfirebase hosting:releases:rollback --release-id=<version-id>\n```\n\n**Solution - Option 3: Manual Rollback**\n```bash\n# Revert code changes\ngit revert <commit-hash>\n\n# Rebuild\nnpm run build\n\n# Redeploy\nfirebase deploy --only hosting\n```\n\n---\n\n## 7. Firebase Console Issues\n\n### Issue: Can't access Firebase Console\n\n**Cause**: Browser issue or permissions\n\n**Solution**:\n```\n1. Try different browser\n2. Clear browser cache\n3. Try incognito/private mode\n4. Check internet connection\n5. Go to https://console.firebase.google.com\n```\n\n---\n\n### Issue: Project not showing in Firebase Console\n\n**Cause**: Wrong Google account or permissions\n\n**Solution**:\n```\n1. Sign out of Firebase Console\n2. Sign in with correct Google account\n3. Project should appear\n4. If not, check project permissions\n```\n\n---\n\n## 8. Network Issues\n\n### Issue: Deployment fails due to network error\n\n**Cause**: Unstable internet connection\n\n**Solution**:\n```bash\n# Check connection\nping google.com\n\n# If no response, fix network\n# Then try deployment again\nfirebase deploy --only hosting\n```\n\n---\n\n### Issue: Deployment is very slow\n\n**Cause**: Slow internet or large files\n\n**Solution**:\n```bash\n# Check file sizes\nls -lh .next/\n\n# If very large, optimize build\n# Then try deployment again\nfirebase deploy --only hosting\n```\n\n---\n\n## 9. Configuration Issues\n\n### Issue: Wrong project deploying\n\n**Cause**: Incorrect `.firebaserc` configuration\n\n**Solution**:\n```bash\n# Check current project\ncat .firebaserc\n\n# Should show: \"default\": \"sari-pos-88979\"\n\n# If wrong, update it\nfirebase use sari-pos-88979\n```\n\n---\n\n### Issue: firebase.json not found\n\n**Cause**: Wrong directory or file deleted\n\n**Solution**:\n```bash\n# Check you're in correct directory\npwd\n# Should show: /Users/macbook/Documents/pos-app-for-stores\n\n# Check firebase.json exists\nls firebase.json\n\n# If missing, restore from git\ngit checkout firebase.json\n```\n\n---\n\n## 10. Emergency Procedures\n\n### Emergency: Disable hosting (take app offline)\n\n```bash\nfirebase hosting:disable\n```\n\nUsers will see: \"Hosting is disabled\"\n\n### Emergency: Re-enable hosting\n\n```bash\nfirebase hosting:enable\n```\n\n### Emergency: Complete reset\n\n```bash\n# 1. Logout\nfirebase logout\n\n# 2. Clean local files\nrm -rf .next node_modules package-lock.json\n\n# 3. Login again\nfirebase login\n\n# 4. Reinstall\nnpm install\n\n# 5. Rebuild\nnpm run build\n\n# 6. Redeploy\nfirebase deploy --only hosting\n```\n\n---\n\n## Getting Help\n\n### Check Logs\n\n```bash\n# Verbose deployment output\nfirebase deploy --only hosting --debug\n\n# View recent deployments\nfirebase hosting:releases:list\n```\n\n### Firebase Console\n\n1.
