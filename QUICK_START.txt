YOUR SYSTEM IS READY! Just need Firebase. 10 minutes.

================================================================================
STEP 1: GET FIREBASE (5 MIN)
================================================================================

1. Go: https://console.firebase.google.com/
2. Click: "+ Add Project"
3. Name: "SariSariPOS"
4. Click: "Create Project"
5. Wait...
6. Firestore Database → Create Database → Production Mode → Create
7. Storage → Get Started → Done

================================================================================
STEP 2: GET CREDENTIALS (2 MIN)
================================================================================

In Firebase Console:
1. Click: ⚙️ Settings (gear icon top left)
2. Go to: "General" tab
3. Scroll down to find your config with:
   - apiKey
   - authDomain
   - projectId
   - storageBucket
   - messagingSenderId
   - appId

Copy these values!

================================================================================
STEP 3: ADD TO YOUR APP (3 MIN)
================================================================================

1. Go to your Vercel project dashboard
2. Settings → Environment Variables
3. Add these 6 variables with your Firebase values:

   NEXT_PUBLIC_FIREBASE_API_KEY
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN
   NEXT_PUBLIC_FIREBASE_PROJECT_ID
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID
   NEXT_PUBLIC_FIREBASE_APP_ID

4. Redeploy your project

DONE! ✅

================================================================================
TEST IT
================================================================================

1. CATEGORIES: Inventory → Add New Category → Type "Test" → Add Category
2. BARCODE: POS → Scan Barcode → Type "123456789" → Confirm
3. COMMISSION: E-Wallet → Commission Settings → Change rate → Save

All three should work with success messages!
