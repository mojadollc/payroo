# Telecom / Digital Provider Logos — 256x256

All files use a uniform 256x256 transparent SVG canvas.

Sizing treatment:
- Square marks: approximately 180x180 visual area.
- Wide wordmarks: approximately 185–190px wide.
- No stretching/distortion.
- Logos are optically centered.
- The SVGs preserve aspect ratio.

Important:
These SVGs reference the online source artwork rather than embedding the artwork locally.
That means they can render when the source URL is reachable, but for a fully self-contained production asset pack the source artwork should be downloaded and embedded/converted locally.
